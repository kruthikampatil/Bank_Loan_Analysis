# 📊 Bank Loan Analysis Project

## 📌 Project Overview

This project focuses on analyzing bank loan data using Excel, SQL, Power BI, and Python to generate meaningful business insights and visualize customer loan trends. The project includes data analysis, dashboard creation, SQL querying, and KPI reporting.

---

# 🛠 Tools & Technologies Used

* Excel
* MySQL
* Power BI
* Python
* Pandas
* NumPy

## 🔹 SQL Analysis

Performed advanced SQL analysis using:

* Subqueries

* Business Analytics Queries

## 🔹 Power BI Dashboard

Created an interactive dashboard for:

* KPI Tracking

## 🔹 Python Analysis

Performed data analysis using:

* Pandas

* Loan trend analysis
* Region-wise loan analysis
* Customer insights
